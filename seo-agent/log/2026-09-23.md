## What I changed, and why

**A. `seo-agent/tools/audit-live.mjs` — the noindex rule now knows the dead-listing gate.**
Left alone, those two lines would have been P0 at the top of every single morning's audit, and a
P0 that is always red is a P0 nobody reads — the exact failure the canonical rule had until 22/09.
A category serving `noindex, follow` where the page rendered cards and **not one** is buyable is
now **P2**; everything else stays P0. The rule is deliberately narrow, because a wrong noindex on
a healthy listing is the bug that cost the best sellers six weeks: it requires `follow` (never
`nofollow`), requires at least one rendered card (so an API outage cannot silence it), requires a
category (never a product), and **one single "En stock" card under a noindex is still a P0**.
Stock is read from the four `getProductStockStatus` labels — the same single definition the card,
the PDP, the cart and the JSON-LD availability use — counted on the script-stripped body so the
flight payload cannot double-count. Validated against the owner's own production census in
`9c9dc83`: `/creatine` 8 in stock / 16 sur commande, identical. Re-run after the change: **exit 0**.

**B. `seo-agent/tools/parity-check.mjs` — a false positive in the tool I built yesterday, found
on its first live run.** It reported **all five** money categories over budget, 719 bot-only
words. Every run was a product card:

    "monohydrate ostrovit- 500gr 149 dt au lieu de 180 dt en stock"
    "kg optimum nutrition 379 dt au lieu de 400 dt en stock"

Not one word of editorial text. The two routes render the same category copy and ask the API for
a different **slice** of the grid, so card text drifts by construction and re-drifts on every
promo. Budgeting it makes the gate permanently red on day one. A bot-only run is now classified by
what survives stripping the card template (prices, "au lieu de", stock labels, pack sizes, bare
numbers): mostly-template = **catalogue drift**, reported in its own column, never budgeted;
still prose = **editorial**, budgeted at 60 exactly as before. Also added the "Accès pro /
Composez votre pack" chrome to the ignore list.

After: **0 editorial bot-only words on all five pages**, 719 catalogue drift, exit 0.

I checked this is a sharper rule and not a rule bent to go green, with a negative control on the
regression the tool was built for:
