## The finding — an infinite redirect loop on every Intra-Workout product

The 33 "Redirect error" URLs are mostly legacy numeric-suffix paths that now 308 once, correctly
(flagged during the 13–14 Sep crawl). One example was different:

```
/Intra-Workout/nutrabio-intra-blast-…-716-g   301 → /intra-workout/nutrabio-…   (middleware lowercases)
/intra-workout/nutrabio-intra-blast-…-716-g   308 → /Intra-Workout/nutrabio-…   (product route "wrong category")
```

Forever. Root cause: `sous_categories` id 43 has the hand-typed slug **`Intra-Workout`** — the
only mixed-case slug in the whole taxonomy (BINARY check on the dump: 1 sous_categories, 0
categories, 0 brands). Middleware's URL contract is lowercase; `util/productUrl.ts` emitted the DB
casing in every builder, and the product route compared `subCategory.slug !== cleanSubCatSlug`
byte-for-byte. Blast radius, measured live: the `/intra-workout` listing links all **12 products**
via `/Intra-Workout/…` (no shopper can open one), and **4 loop URLs are in products-*.xml**. July's
ca56ff57 had already noticed the capitalised slug and patched the sitemap *around* it.
